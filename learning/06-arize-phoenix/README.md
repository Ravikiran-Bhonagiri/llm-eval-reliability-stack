- 10,000+ tickets/month
- 4 specialized AI agents

**The Architecture**:
```
incoming_ticket
   ↓
router_agent → classifies issue type
   ↓
   ├→ technical_agent (handles tech issues)
   ├→ billing_agent (handles payments)
   ├→ escalation_agent (handles complaints)
   └→ response
   
[EVERY step traced in Phoenix!]
```

**Phoenix Observability**:
```python
# Every agent action traced
with tracer.start_as_current_span("process_ticket") as span:
    classification = router.classify(ticket)
    response = agents[classification].handle(ticket)
    
    span.set_attribute("agent_used", classification)
    span.set_attribute("ticket_id", ticket.id)
    span.set_attribute("latency_ms", elapsed)
    span.set_attribute("tokens_used", tokens)
    span.set_attribute("cost_usd", cost)
```
