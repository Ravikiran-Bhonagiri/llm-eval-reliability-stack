## 🎁 Bonus: Quick Reference Card

### Essential Commands
```bash
# Initialize project
promptfoo init

# Run evaluation
promptfoo eval

# View results in browser
promptfoo view

# Run with specific config
promptfoo eval -c config.yaml

# Generate shareable URL
promptfoo eval --share

# Output to JSON
promptfoo eval -o results.json

# Red team mode
promptfoo redteam run

# No cache (fresh results)
promptfoo eval --no-cache
```

### Essential Config Patterns
```yaml
# Minimal config
prompts: [prompt.txt]
providers: [openai:gpt-4]
tests:
  - vars: {input: "test"}
    assert: [{type: contains, value: "ok"}]

# Production config
prompts: file://prompts/**/*.txt
providers: file://providers.yaml
tests:
  - file://tests/*.yaml
defaultTest:
  assert:
    - type: latency
      threshold: 3000
redteam:
  enabled: true
```
